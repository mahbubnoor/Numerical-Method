Why Numerical Methods?

When no formula exists, we compute the answer step by step: guess, improve, repeat, and stop when it is good enough.

Today's goals

  • Explain why many real problems have no exact formula and need numerical methods

Start with any reasonable guess for √2.Apply a rule that makes the guess better.Check: has the value stopped changing?Not yet, so go round the loop again.Each trip round the loop adds correct digits.Four trips: the digits have almost stopped moving.Two guesses in a row now agree to 5 decimals.Stop and report the answer. That loop is "iteration".
In plain words
  • A numerical method is a recipe of simple arithmetic steps, repeated
  • Each repeat (iteration) improves the answer a little
  • We stop when the answer is good enough for our purpose

Many problems have no formula to plug into

Each of these is easy to state and has an answer, yet no finite formula gives it exactly.

Equation

Solve x=cos⁡xx = \cos xx=cosx

No algebra isolates xxx. The answer is x≈0.739085x \approx 0.739085x≈0.739085, found only by computing.

Polynomial

Solve x5−x−1=0x^5 - x - 1 = 0x5−x−1=0

Abel (1824): there is no general formula for polynomials of degree 5 or more.

Integral

∫01e−x2 dx\int_0^1 e^{-x^2}\,dx∫01​e−x2dx

e−x2e^{-x^2}e−x2 has no elementary antiderivative, yet the area is a definite number ≈ 0.746824.

Differential equation

Pendulum θ′′=−gLsin⁡θ\theta'' = -\frac{g}{L}\sin\thetaθ′′=−Lg​sinθ

No formula for θ(t)\theta(t)θ(t) in elementary functions; games and simulators step it forward numerically.

Large system

Ax=bA\mathbf{x} = \mathbf{b}Ax=b with 10610^6106 unknowns

Cramer's rule would need about 106!10^{6}!106! operations. Elimination or iteration is the only way.

Data

Fit a line to 10,000 points

The data have noise; no line passes through all points. We compute the best line (least squares).

Analytical vs numerical solution

Analytical (exact)

  • A formula or symbolic expression
  • Exact: x=−b±b2−4ac2ax = \frac{-b \pm \sqrt{b^2-4ac}}{2a}x=2a−b±b2−4ac​​
  • Works for every input of that form at once
  • Often impossible for real problems
  • Example: ∫01x2 dx=13\int_0^1 x^2\,dx = \tfrac{1}{3}∫01​x2dx=31​
vs

Numerical (approximate)

  • An algorithm: a finite list of arithmetic steps
  • A number: x≈0.739085x \approx 0.739085x≈0.739085
  • Must be re-run for each new input
  • Works on almost any problem a computer can evaluate
  • Comes with an error we must estimate and control

An algorithm, an error estimate and a stopping rule: those three things together make a numerical method.

When do we stop iterating?

An iteration never reaches the exact answer, so we must decide when it is close enough.

Absolute change∣xk+1−xk∣<ε|x_{k+1} - x_k| < \varepsilon∣xk+1​−xk​∣<ε
Relative change (scale-free)∣xk+1−xk∣∣xk+1∣<ε\dfrac{|x_{k+1} - x_k|}{|x_{k+1}|} < \varepsilon∣xk+1​∣∣xk+1​−xk​∣​<ε
Residual (for f(x) = 0)∣f(xk+1)∣<ε|f(x_{k+1})| < \varepsilon∣f(xk+1​)∣<ε
  • Use relative change when xxx may be very large or very small
  • A small change does not guarantee a small error, but for converging methods it is a good estimate
  • Always add a maximum number of iterations: if the method diverges, the loop must still end
  • "Correct to ddd decimal places" means ∣xk+1−xk∣<0.5×10−d|x_{k+1} - x_k| < 0.5 \times 10^{-d}∣xk+1​−xk​∣<0.5×10−d

What makes a numerical method good?

Accurate

The error can be made as small as we need, and we can estimate it.

Efficient

Few operations per step and few steps. Cost matters when n=106n = 10^6n=106.

Stable

Small round-off errors stay small instead of growing (Lecture 5).

Robust

Works for many inputs; fails loudly, not silently.

No method wins on all four. Bisection is robust but slow; Newton is fast but can fail. Choosing the method for the problem is the skill this course builds.

Beyond the classroom

Where this shows up in CSE and machine learning

🧠

Training a neural network

Each epoch is one iteration wk+1=wk−η∇L(wk)w_{k+1} = w_k - \eta \nabla L(w_k)wk+1​=wk​−η∇L(wk​). The stopping rule is a tolerance on the loss or a maximum number of epochs: exactly today's two tests.

🎮

Game physics at 60 frames per second

Every frame advances positions with a numerical ODE step. Too large a step and objects fly through walls: a stability failure.

📈

Recommendation and ranking

PageRank and many recommender systems repeat xk+1=Mxkx_{k+1} = Mx_kxk+1​=Mxk​ until the vector stops changing.

🔊

Speech processing

Pitch tracking finds roots of a correlation function; enhancement solves least-squares problems frame by frame.

Summary

Key points
  • Many problems (equations, integrals, ODEs, big systems, noisy data) have no exact formula
  • A numerical method = algorithm + error estimate + stopping rule
  • Iteration: guess → improve → check → repeat; Babylonian N\sqrt{N}N​ doubles the correct digits each step
  • Stop on absolute or relative change, or residual, and always cap the iterations
  • Bracketing methods are safe but slow; open methods are fast but can diverge
