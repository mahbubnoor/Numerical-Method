Why this lecture

The problem: the census is every ten years

A town's population (thousands) was counted every ten years. A planner needs the values for 1895 and 1925, when no count was taken.

  • The data are equally spaced (h=10h = 10h=10 years) but there is no formula
  • 1895 is near the start of the table; 1925 is near the end
  • Straight-line interpolation ignores the curvature that the differences show
  • We need a formula that uses the whole table, and an idea of its error

The method, step by step

Newton's forward interpolation, step by step

  1. Check the xxx values are equally spaced; note hhh
  2. Build the forward difference table
  3. Take x0x_0x0​ as the table entry just below xxx (near the start); compute p=(x−x0)/hp = (x - x_0)/hp=(x−x0​)/h
  4. Add terms p(p−1)⋯(p−k+1)k! Δky0\dfrac{p(p-1)\cdots(p-k+1)}{k!}\,\Delta^k y_0k!p(p−1)⋯(p−k+1)​Δky0​ for k=0,1,2,…k = 0, 1, 2, \dotsk=0,1,2,…
  5. Stop when the terms become negligible (or the table ends); the last term used estimates the error
Pseudocode
input x[0..n], y[0..n] (equal steps), X
h ← x[1] − x[0];  p ← (X − x[0]) / h
d ← copy of y          # top diagonal
sum ← d[0];  c ← 1
for k = 1 … n:
    for i = 0 … n−k:
        d[i] ← d[i+1] − d[i]
    c ← c·(p − k + 1) / k
    sum ← sum + c·d[0]
return sum

Each pass makes the next column of differences in place; only d0d_0d0​ is used.

Numerical (Newton forward)

  • p=0.4p = 0.4p=0.4, five short terms

When the classical approach cannot work

Data from experiments and records

Population, rainfall or sensor logs have no formula to find. Even fitting one through the points with xxx as large as 1931 makes a severely ill-conditioned system (Lecture 11). Newton's formula works in the shifted variable ppp, where all numbers are small.

When interpolation goes wrong

Limitations shown failing

  • High degree on equal spacing: 11 points of 1/(1+25x2)1/(1 + 25x^2)1/(1+25x2); near the ends the degree-10 polynomial swings far from the data
  • Extrapolation: outside the table the error term grows without control
  • Unequal spacing: the formulas do not apply at all
  • Noisy data: high differences are mostly noise, so extra terms add error

When to use it

Newton's forward and backward formulas: method profile

Best case
  • Smooth, equally spaced tables; xxx close to the start (forward) or end (backward)
  • Low-degree data: exact once the differences vanish
  • Hand calculation: the difference table organises all the work
Worst case
  • Extrapolation far outside the table
  • Many equally spaced points with a high-degree polynomial (Runge, Lecture 18)
  • Noisy measurements: high differences amplify noise
Best suited for
  • Tables of functions, physical properties (steam tables), census-type records
  • Deriving differentiation and integration formulas (Lectures 19–20)
  • Resampling equally spaced signals
Avoid when
  • Unequally spaced data (use Lagrange or divided differences, Lecture 17)
  • Long tables needing a smooth curve everywhere (use splines, Lecture 18)
  • Data with errors (use least squares, Lecture 23)

Rule of thumb: forward near the top, backward near the bottom, central formulas in the middle; never far outside the table.

Summary

Key points
  • Forward: y=y0+pΔy0+p(p−1)2!Δ2y0+⋯y = y_0 + p\Delta y_0 + \tfrac{p(p-1)}{2!}\Delta^2 y_0 + \cdotsy=y0​+pΔy0​+2!p(p−1)​Δ2y0​+⋯, p=(x−x0)/hp = (x - x_0)/hp=(x−x0​)/h
  • Backward: y=yn+p∇yn+p(p+1)2!∇2yn+⋯y = y_n + p\nabla y_n + \tfrac{p(p+1)}{2!}\nabla^2 y_n + \cdotsy=yn​+p∇yn​+2!p(p+1)​∇2yn​+⋯, p=(x−xn)/hp = (x - x_n)/hp=(x−xn​)/h
  • Forward near the start, backward near the end; the first neglected term estimates the error
  • Only for equal spacing; extrapolation and high degree are dangerous
