The method, step by step

The Newton–Raphson algorithm

  1. Find f′(x)f'(x)f′(x); choose x0x_0x0​ near the root (from a sketch or a sign change)
  2. Compute xn+1=xn−f(xn)f′(xn)x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)}xn+1​=xn​−f′(xn​)f(xn​)​
  3. If f′(xn)=0f'(x_n) = 0f′(xn​)=0 (flat tangent), stop and choose another x0x_0x0​
  4. Repeat until ∣xn+1−xn∣<ε|x_{n+1} - x_n| < \varepsilon∣xn+1​−xn​∣<ε (the required digits stop changing)
  5. Answer: the last xn+1x_{n+1}xn+1​; check that f(xn+1)≈0f(x_{n+1}) \approx 0f(xn+1​)≈0
Pseudocode
input f, df, x0, tol, N
x ← x0
repeat up to N times:
    d ← df(x)
    if d = 0: stop (flat tangent)
    x_new ← x − f(x) / d
    if |x_new − x| < tol:
        return x_new
    x ← x_new
stop: no convergence

One function value and one derivative value per step. No bracket, so nothing guarantees convergence: the cap NNN matters.

When the classical approach cannot work

The quintic x5−x−1=0x^5 - x - 1 = 0x5−x−1=0

Abel–Ruffini theorem (1824): there is no formula in radicals for general degree-5 equations, and this one is a standard example. Newton from x0=1x_0 = 1x0​=1: x=1.167304x = 1.167304x=1.167304 in 5 iterations.

Even where a formula exists, numerical methods are often simpler and more accurate; beyond degree 4 they are the only general option.

When to use it

Newton–Raphson: method profile

Best case
  • Simple root, good start, cheap f′f'f′: digits double; x3−x−2x^3 - x - 2x3−x−2 from 1.5 in 3 steps, x2−4x−10x^2 - 4x - 10x2−4x−10 from 5 in 4
  • Square roots, reciprocals and Kepler's equation: 3–6 steps to full precision
  • Extends directly to systems (L10) and optimisation (L25)
Worst case
  • Start near f′(x)=0f'(x) = 0f′(x)=0: from x0=0.6x_0 = 0.6x0​=0.6 the first step jumps to 30.4; 13 steps in total
  • Cycles (x3−2x+2x^3 - 2x + 2x3−2x+2 from 0) or divergence (tan⁡−1x\tan^{-1}xtan−1x from 1.5)
  • Double root (x−1)2(x - 1)^2(x−1)2: only linear, the error just halves
  • No formula for f′f'f′, or fff is noisy
Best suited for
  • Smooth fff with an easy derivative, when a good starting value is known
  • Refining an estimate from bisection (hybrid methods)
  • Hardware: square root, division, inverse square root; ML: second-order optimisers
Avoid when
  • f′f'f′ unavailable or expensive (use secant, L10)
  • No idea where the root is (bracket first)
  • Multiple roots, unless you use x−mf/f′x - m f/f'x−mf/f′ with known multiplicity mmm

Rule of thumb: bracket first, then Newton. Safety from bisection, speed from the tangent.
