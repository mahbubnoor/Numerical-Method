Solving nonlinear equations · Lecture 7

The False Position Method

Bisection ignores how big f(a) and f(b) are. False position draws the straight line between them and takes its crossing: usually much faster, still safely bracketed.

The problem: bisection throws information away

Bisection needed 20 steps for x3−x−2=0x^3 - x - 2 = 0x3−x−2=0 on [1,2][1, 2][1,2]. Look at what it ignored.

  • f(1)=−2f(1) = -2f(1)=−2 and f(2)=4f(2) = 4f(2)=4: the function is twice as far from zero at x=2x = 2x=2 as at x=1x = 1x=1
  • Common sense: the root should be about one third of the way from 1 to 2, not in the middle
  • Bisection used only the signs −-− and +++; the sizes 2 and 4 were thrown away

The idea: follow the chord

Set y = 0 and solve for xc=b−f(b) b−af(b)−f(a)  =  a f(b)−b f(a)f(b)−f(a)c = b - f(b)\,\frac{b - a}{f(b) - f(a)} \;=\; \frac{a\,f(b) - b\,f(a)}{f(b) - f(a)}c=b−f(b)f(b)−f(a)b−a​=f(b)−f(a)af(b)−bf(a)​

The method, step by step

The false position algorithm

  1. Start with [a,b][a, b][a,b] where f(a) f(b)<0f(a)\,f(b) < 0f(a)f(b)<0
  2. Chord point c=a f(b)−b f(a)f(b)−f(a)c = \dfrac{a\,f(b) - b\,f(a)}{f(b) - f(a)}c=f(b)−f(a)af(b)−bf(a)​; compute f(c)f(c)f(c)
  3. If f(a) f(c)<0f(a)\,f(c) < 0f(a)f(c)<0, the root is in [a,c][a, c][a,c]: set b=cb = cb=c
  4. Otherwise the root is in [c,b][c, b][c,b]: set a=ca = ca=c (if f(c)=0f(c) = 0f(c)=0, stop: ccc is the root)
  5. Repeat until two successive ccc agree: ∣cn−cn−1∣<ε|c_n - c_{n-1}| < \varepsilon∣cn​−cn−1​∣<ε; the answer is the last ccc
Pseudocode
input f, a, b, tol
fa ← f(a);  fb ← f(b)
if fa·fb > 0: stop (no bracket)
c_old ← a
repeat up to N times:
    c  ← (a·fb − b·fa) / (fb − fa)
    fc ← f(c)
    if fc = 0 or |c − c_old| < tol:
        return c
    if fa·fc < 0:  b ← c;  fb ← fc
    else:          a ← c;  fa ← fc
    c_old ← c

Only step 2 differs from bisection. The stopping test changes too, because one end of the bracket may never move, so (b−a)(b - a)(b−a) need not shrink.

When to use it

False position: method profile

Best case
  • fff nearly straight on the bracket: on a straight line it is exact in 1 step (bisection needs 20)
  • Smooth, gently curved fff: x3−x−2x^3 - x - 2x3−x−2 and ex−3xe^x - 3xex−3x need 12 steps for 10−610^{-6}10−6, bisection 20
  • Keeps the bracket: it can never lose the root
Worst case
  • Strong curvature with the root near one end: x10−1x^{10} - 1x10−1 on [0,1.3][0, 1.3][0,1.3] needs 57 steps (bisection 21)
  • One endpoint stays fixed, so the bracket never shrinks and gives no useful error bound
  • Same as bisection: needs a sign change, fooled by poles
Best suited for
  • Smooth monotone functions where a bracket is available
  • Inverting tables and calibration curves (one step = linear interpolation)
  • The Illinois variant: a cheap, safe default for 1-D problems
Avoid when
  • fff is strongly convex or concave on the bracket
  • You need an error bound at every step (use bisection)
  • f′f'f′ is available and you want quadratic speed (use Newton)

Rule of thumb: prefer Illinois to plain false position; it keeps the speed on easy problems and fixes the stall on hard ones.
