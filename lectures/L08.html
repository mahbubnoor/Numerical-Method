Fixed-Point Iteration

Rewrite f(x) = 0 as x = g(x), then just repeat x ← g(x). It works beautifully, or explodes, depending on one number: the slope of g at the root.

The idea in one picture

We want the x where the curve y = cos x meets the line y = x.Pick a starting value x₀.Go up to the curve: that height is cos x₀.Go across to the line y = x: this turns the height into the next x.Up (or down) to the curve again …… and across to the line again.The path winds inwards like a spiral.Every loop lands closer.Up to the curve …… across to the line.It settles at 0.739: the fixed point, where x = cos x.
In plain words
  • Rewrite the equation as x = g(x)
  • Put a guess into g; the result is the next guess
  • If g is "flat enough" near the answer, the guesses settle down
New words today
fixed point
a value that g leaves unchanged: r = g(r)
iterate
one of the successive guesses x₀, x₁, x₂, …
cobweb diagram
the up-and-across picture on the left
converges if
|g′(x)| < 1 near the root
contraction
a g that pulls any two points closer together

When does it converge?

Error recursion (mean value theorem)xn+1−r=g(xn)−g(r)=g′(ξn)(xn−r)x_{n+1} - r = g(x_n) - g(r) = g'(\xi_n)(x_n - r)xn+1​−r=g(xn​)−g(r)=g′(ξn​)(xn​−r)
Convergence condition∣g′(x)∣≤L<1 near r  ⟹  ∣xn−r∣≤Ln ∣x0−r∣→0|g'(x)| \le L < 1 \text{ near } r \;\Longrightarrow\; |x_n - r| \le L^{n}\,|x_0 - r| \to 0∣g′(x)∣≤L<1 near r⟹∣xn​−r∣≤Ln∣x0​−r∣→0
  • Each step multiplies the error by about g′(r)g'(r)g′(r): linear convergence, rate ∣g′(r)∣|g'(r)|∣g′(r)∣
  • ∣g′(r)∣>1|g'(r)| > 1∣g′(r)∣>1: errors grow, the iteration moves away from rrr
  • Smaller ∣g′(r)∣|g'(r)|∣g′(r)∣ = faster; g′(r)=0g'(r) = 0g′(r)=0 is very fast (that is Newton, next lecture)
  • Sign of g′g'g′: positive → staircase (one-sided); negative → spiral (alternating sides)

The method, step by step

The fixed-point iteration algorithm

  1. Rewrite f(x)=0f(x) = 0f(x)=0 as x=g(x)x = g(x)x=g(x) (there are many ways)
  2. Pick a ggg with ∣g′(x)∣<1|g'(x)| < 1∣g′(x)∣<1 near the root; choose a starting value x0x_0x0​
  3. Compute xn+1=g(xn)x_{n+1} = g(x_n)xn+1​=g(xn​)
  4. Repeat until ∣xn+1−xn∣<ε|x_{n+1} - x_n| < \varepsilon∣xn+1​−xn​∣<ε; the answer is the last xxx
  5. If the values grow or jump about, stop and choose a different ggg
Pseudocode
input g, x0, tol, N
x ← x0
repeat up to N times:
    x_new ← g(x)
    if |x_new − x| < tol:
        return x_new
    x ← x_new
stop: no convergence (try another g)

The loop is the shortest in the course. All the skill is in step 2: choosing a ggg that contracts.

When to use it

Fixed-point iteration: method profile

Best case
  • ∣g′(r)∣|g'(r)|∣g′(r)∣ small: Kepler's equation E=1+0.1sin⁡EE = 1 + 0.1\sin EE=1+0.1sinE converges in 5 steps
  • g′(r)=0g'(r) = 0g′(r)=0: much faster than linear (this is Newton's method, L9)
  • The problem is already in the form x=g(x)x = g(x)x=g(x): no derivative, one line of code
Worst case
  • ∣g′(r)∣|g'(r)|∣g′(r)∣ close to 1: x=cos⁡xx = \cos xx=cosx needs 36 steps; Kepler with e=0.9e = 0.9e=0.9 needs 11
  • ∣g′(r)∣>1|g'(r)| > 1∣g′(r)∣>1: diverges, e.g. x=(x2−10)/4x = (x^2 - 10)/4x=(x2−10)/4 for the root 5.7417
  • The choice of ggg is guesswork without the ∣g′∣<1|g'| < 1∣g′∣<1 test
Best suited for
  • Equilibrium problems: PageRank, Bellman value iteration, EM, Kepler's equation
  • Large linear systems (Jacobi, Gauss–Seidel are fixed-point iterations, L14)
  • Quick prototypes where a contraction ggg is obvious
Avoid when
  • No rearrangement with ∣g′∣<1|g'| < 1∣g′∣<1 is known
  • High accuracy is needed quickly (linear convergence)
  • You need a guarantee from any start (use bracketing)

Rule of thumb: check ∣g′∣|g'|∣g′∣ before iterating; the smaller it is, the fewer steps you need (about −1/log⁡10∣g′∣-1/\log_{10}|g'|−1/log10​∣g′∣ steps per digit).

Summary

Key points
  • Rewrite f(x)=0f(x) = 0f(x)=0 as x=g(x)x = g(x)x=g(x) and iterate xn+1=g(xn)x_{n+1} = g(x_n)xn+1​=g(xn​)
