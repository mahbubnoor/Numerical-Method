Conditioning and Stability

Some problems magnify every tiny error, and no algorithm can save them. Some algorithms ruin perfectly good problems. Telling the two apart is the most important diagnostic skill in numerical computing.

Problem vs algorithm

Conditioning (the problem)

  • How much does the exact answer change when the input changes a little?
  • Measured by the condition number κ\kappaκ
  • Well-conditioned: κ\kappaκ small (≈ 1–100)
  • Ill-conditioned: κ\kappaκ huge; data errors are amplified
  • No algorithm can fix it; only better data, more precision or a reformulated problem
≠

Stability (the algorithm)

  • Does the algorithm keep its own rounding errors small?
  • Stable: the answer is as good as the conditioning allows
  • Unstable: errors grow inside the algorithm (e.g. by n!n!n! or by 10810^{8}108)
  • Fixable: choose a different algorithm for the same problem
  • Examples: pivoting, rewriting formulas, backward recurrence

Accurate result ⇐ well-conditioned problem + stable algorithm. You need both.

Diagnosing an inaccurate answer

well-conditioned + stable

Accurate ✓

x\sqrt{x}x​, Gaussian elimination with pivoting on a good matrix, 2sin⁡2(x/2)2\sin^2(x/2)2sin2(x/2).

well-conditioned + unstable

Inaccurate, but fixable

Change the algorithm: pivot, rewrite, reverse the recurrence.

ill-conditioned + stable

Inaccurate, algorithm is innocent

Change the problem: better data, more precision, rescale, regularise. Hilbert matrix, nearly parallel lines.

ill-conditioned + unstable

Hopeless

Fix the algorithm first, then deal with the conditioning.

Beyond the classroom

Where this shows up in CSE and machine learning

📐

Feature scaling

Features in metres and in millimetres make the normal-equations matrix ill-conditioned. Standardising features (mean 0, std 1) reduces κ\kappaκ and speeds up training.

🛡️

Ridge regularisation

Solving (XTX+λI)w=XTy(X^TX + \lambda I)\mathbf{w} = X^T\mathbf{y}(XTX+λI)w=XTy instead of XTXw=XTyX^TX\mathbf{w} = X^T\mathbf{y}XTXw=XTy caps the condition number: a cure for ill-conditioning (Lecture 23).

⛰️

Ill-conditioned loss surfaces

When the Hessian's eigenvalues differ a lot (ratio = κ\kappaκ), gradient descent zig-zags: exactly the situation studied in Lecture 25.

🔢

Adam's epsilon

Optimisers divide by v+ϵ\sqrt{v} + \epsilonv​+ϵ with ϵ=10−8\epsilon = 10^{-8}ϵ=10−8 so that a tiny denominator cannot amplify noise: a stability safeguard.

Summary

Key points
  • Conditioning belongs to the problem; stability to the algorithm
  • κf=∣xf′(x)/f(x)∣\kappa_f = |xf'(x)/f(x)|κf​=∣xf′(x)/f(x)∣; κ(A)=∥A∥∥A−1∥\kappa(A) = \|A\|\|A^{-1}\|κ(A)=∥A∥∥A−1∥; digits lost ≈ log⁡10κ\log_{10}\kappalog10​κ
  • Ill-conditioned: change the data or the problem. Unstable: change the algorithm
  • Forward error ≲ κ × backward error; a backward-stable algorithm solves a nearby problem exactly
