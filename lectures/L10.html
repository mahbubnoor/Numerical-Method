The problem: a function with no formula

The game designer from Lecture 6 asks: at what launch speed vvv does the ball land after exactly 3 seconds?

  • Define T(v)T(v)T(v) = landing time for launch speed vvv. We need T(v)−3=0T(v) - 3 = 0T(v)−3=0
  • But T(v)T(v)T(v) has no formula: every evaluation is a whole bisection run (Lecture 6)
  • So there is no derivative T′(v)T'(v)T′(v) for Newton, and each evaluation is expensive
  • We need a fast method that uses only values of the function

The idea in one picture

Like Newton, but we do not know the slope (derivative).Take two starting points on the curve.Draw the straight line through them.Where it crosses the axis is the next point x₂.Forget the oldest point; keep the two newest.Line through the two newest points …… gives x₃.Drop the oldest again.The line through x₂ and x₃ is almost the tangent.x₄ = 1.531 (root 1.521): nearly as fast as Newton, with no derivative.
In plain words
  • Newton needs the derivative, which we often do not have
  • Replace the tangent by the line through the two latest points
  • Almost as fast, and only function values are needed

The secant method

The method, step by step

The secant algorithm

  1. Choose two starting values x0x_0x0​, x1x_1x1​ near the root (they need not bracket it)
  2. Compute xn+1=xn−f(xn) xn−xn−1f(xn)−f(xn−1)x_{n+1} = x_n - f(x_n)\,\dfrac{x_n - x_{n-1}}{f(x_n) - f(x_{n-1})}xn+1​=xn​−f(xn​)f(xn​)−f(xn−1​)xn​−xn−1​​
  3. If f(xn)=f(xn−1)f(x_n) = f(x_{n-1})f(xn​)=f(xn−1​) (flat secant), stop
  4. Drop the oldest point: the pair (xn−1,xn)(x_{n-1}, x_n)(xn−1​,xn​) becomes (xn,xn+1)(x_n, x_{n+1})(xn​,xn+1​)
  5. Repeat until ∣xn+1−xn∣<ε|x_{n+1} - x_n| < \varepsilon∣xn+1​−xn​∣<ε; the answer is the last xxx
Pseudocode
input f, x0, x1, tol, N
f0 ← f(x0);  f1 ← f(x1)
repeat up to N times:
    if f1 = f0: stop (flat secant)
    x2 ← x1 − f1·(x1 − x0) / (f1 − f0)
    if |x2 − x1| < tol:
        return x2
    x0, f0 ← x1, f1
    x1, f1 ← x2, f(x2)
stop: no convergence

Step 4 is the only difference from false position: no sign test, just keep the newest two points.

Solve f1(x,y)=0f_1(x, y) = 0f1​(x,y)=0, f2(x,y)=0f_2(x, y) = 0f2​(x,y)=0 simultaneously. Linearise both with Taylor series:

The method, step by step

Newton for systems, step by step

  1. Write F=(f1,f2)\mathbf{F} = (f_1, f_2)F=(f1​,f2​) and the Jacobian JJJ (four partial derivatives)
  2. Choose a starting guess (x0,y0)(x_0, y_0)(x0​,y0​)
  3. Evaluate F\mathbf{F}F and JJJ at the current point
  4. Solve the linear system J Δ=−FJ\,\Delta = -\mathbf{F}JΔ=−F (2×2: Cramer's rule)
  5. Update xn+1=xn+Δ\mathbf{x}_{n+1} = \mathbf{x}_n + \Deltaxn+1​=xn​+Δ
  6. Repeat until ∥Δ∥<ε\|\Delta\| < \varepsilon∥Δ∥<ε; the answer is the last x\mathbf{x}x
Pseudocode
input F, J, x0, tol, N
x ← x0
repeat up to N times:
    solve J(x)·Δ = −F(x)
    x ← x + Δ
    if ‖Δ‖ < tol:
        return x
stop: no convergence

Same loop as one-variable Newton; "divide by f′f'f′" became "solve with JJJ" (step 4).

When the secant method fails

  • Divergence: tan⁡−1x\tan^{-1}xtan−1x from 2, 3 jumps to −5.80, −1.15, 6.15, … 38.6
  • Flat secant: cos⁡(−1)=cos⁡(1)\cos(-1) = \cos(1)cos(−1)=cos(1), the line is horizontal: division by zero
  • Wandering: x3−2x+2x^3 - 2x + 2x3−2x+2 from 0, 0.5 jumps around for many steps before settling
  • No bracket means no guarantee: same weakness as Newton

When to use it

Secant method: method profile

Best case
  • Smooth fff, two good starting values: superlinear, order 1.618; x3−x−2x^3 - x - 2x3−x−2 in 7 steps
  • Expensive fff with no derivative: one evaluation per step, the most efficient per evaluation
  • The ball problem: 4 steps, each a full simulation
Worst case
  • f(xn)≈f(xn−1)f(x_n) \approx f(x_{n-1})f(xn​)≈f(xn−1​): a nearly flat secant throws the next point far away
  • Poor starting values: divergence (tan⁡−1x\tan^{-1}xtan−1x from 2, 3)
  • Cancellation in f(xn)−f(xn−1)f(x_n) - f(x_{n-1})f(xn​)−f(xn−1​) near convergence limits the final accuracy slightly
Best suited for
  • Black-box functions: simulations, measurements, outputs of other solvers
  • Inside hybrid solvers (Brent's method, scipy.optimize.brentq)
  • When f′f'f′ costs as much as fff
Avoid when
  • A guaranteed result is needed (bracket it, or use Brent)
  • The function is noisy (secant slopes amplify noise; use bisection)
  • A cheap derivative is available and starts are good (Newton is slightly faster per iteration)

Rule of thumb: no derivative → secant; no guarantee needed → plain; guarantee needed → Brent (bracket + secant + bisection).
