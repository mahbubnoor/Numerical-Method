Why this lecture

The problem: currents in a circuit

Kirchhoff's voltage law around each loop of a three-loop circuit gives three equations for the loop currents I1,I2,I3I_1, I_2, I_3I1​,I2​,I3​ (amperes).

  • Every loop equation is linear in the currents: resistances times currents add up to the source voltage
  • Three loops: three equations. A phone charger board: dozens. A chip: millions
  • School gives two formulas: Cramer's rule and x=A−1b\mathbf{x} = A^{-1}\mathbf{b}x=A−1b
  • Today: use them, count their cost, and see where they fail. A 25-loop circuit by Cramer's rule would take longer than the age of the universe

The idea in one picture

Each linear equation in x and y is a straight line. Solving = finding the crossing.Parallel lines never meet: the equations contradict each other.The same line twice: every point on it is a solution.One number, the determinant, tells the cases apart.
In plain words
  • Each linear equation is a line (or a plane); solving means finding the common point
  • Usually there is exactly one, but sometimes none or infinitely many
  • School formulas work for 2 or 3 unknowns, and become hopeless for many
New words today
system Ax = b
all equations written with one matrix A
determinant
one number that is zero exactly when there is no unique solution
inverse A⁻¹
the matrix that undoes A
norm
a single number for the size of a vector or matrix

The method, step by step

Cramer's rule, step by step

  1. Write the system as [A∣b][A \mid \mathbf{b}][A∣b]
  2. Compute D=det⁡AD = \det AD=detA. If D=0D = 0D=0, stop: no unique solution
  3. For each i=1,…,ni = 1, \dots, ni=1,…,n: copy AAA, replace column iii by b\mathbf{b}b, compute its determinant DiD_iDi​
  4. Set xi=Di/Dx_i = D_i / Dxi​=Di​/D
  5. Check: substitute x\mathbf{x}x into every equation
Pseudocode
input A (n×n), b
D ← det(A)
if D = 0: stop (singular)
for i = 1 … n:
    Aᵢ ← A with column i := b
    x[i] ← det(Aᵢ) / D
return x

det(M):  # cofactor expansion
    if size 1: return m₁₁
    return Σⱼ (−1)^(1+j) m₁ⱼ det(M₁ⱼ)

The recursion in det is where all the work goes: one call of size nnn makes nnn calls of size n−1n - 1n−1.

The method, step by step

The inverse method, step by step

  1. Compute D=det⁡AD = \det AD=detA; if D=0D = 0D=0, stop
  2. Compute all n2n^2n2 cofactors Cij=(−1)i+jMijC_{ij} = (-1)^{i+j}M_{ij}Cij​=(−1)i+jMij​
  3. Transpose: adj⁡A=CT\operatorname{adj}A = C^{T}adjA=CT
  4. Divide: A−1=adj⁡A/DA^{-1} = \operatorname{adj}A / DA−1=adjA/D; check AA−1=IAA^{-1} = IAA−1=I
  5. Multiply: x=A−1b\mathbf{x} = A^{-1}\mathbf{b}x=A−1b
Pseudocode
input A (n×n), b
D ← det(A)
if D = 0: stop (singular)
for i, j = 1 … n:
    C[i][j] ← (−1)^(i+j) · det(minor(A, i, j))
Ainv ← transpose(C) / D
for i = 1 … n:
    x[i] ← Σⱼ Ainv[i][j] · b[j]
return x

n2n^2n2 cofactors, each a determinant of size n−1n - 1n−1: even more work than Cramer for one right-hand side.

Limitations shown failing

Limitations 2 and 3: determinants and inverses in floating point

Underflow

det⁡(0.1 I400)=10−400\det(0.1\,I_{400}) = 10^{-400}det(0.1I400​)=10−400

Below the smallest double (4.9×10−3244.9\times10^{-324}4.9×10−324, Lecture 2), so the computer stores 0 and Cramer reports "singular". Yet the system is trivial: x=10 b\mathbf{x} = 10\,\mathbf{b}x=10b.

Overflow

det⁡(10 I400)=10400\det(10\,I_{400}) = 10^{400}det(10I400​)=10400

Overflows to infinity, and every xi=Di/Dx_i = D_i/Dxi​=Di​/D becomes ∞/∞\infty/\infty∞/∞ = NaN. The size of the determinant says nothing useful about the system.

Waste

A−1A^{-1}A−1 then A−1bA^{-1}\mathbf{b}A−1b

Even with a good method for the inverse, it costs about 2n32n^32n3 operations, three times elimination, and adds extra rounding errors. Numerical analysts rarely form A−1A^{-1}A−1.

A small determinant does not mean trouble, and a large one does not mean safety. What does measure trouble? The condition number, next.
