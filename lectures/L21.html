  1. Write the problem as y′=f(x,y)y' = f(x, y)y′=f(x,y), y(x0)=y0y(x_0) = y_0y(x0​)=y0​; choose hhh
  2. Evaluate the slope f(xn,yn)f(x_n, y_n)f(xn​,yn​) at the current point
  3. Step: yn+1=yn+h f(xn,yn)y_{n+1} = y_n + h\,f(x_n, y_n)yn+1​=yn​+hf(xn​,yn​),   xn+1=xn+h\;x_{n+1} = x_n + hxn+1​=xn​+h

The method, step by step

Modified Euler (Heun), step by step

  1. Slope at the start: k1=f(xn,yn)k_1 = f(x_n, y_n)k1​=f(xn​,yn​)
  2. Predict with Euler: y∗=yn+h k1y^{*} = y_n + h\,k_1y∗=yn​+hk1​
  3. Slope at the predicted end point: k2=f(xn+h,y∗)k_2 = f(x_n + h, y^{*})k2​=f(xn​+h,y∗)
  4. Correct: yn+1=yn+h2(k1+k2)y_{n+1} = y_n + \dfrac h2(k_1 + k_2)yn+1​=yn​+2h​(k1​+k2​)
  5. (Optional) recompute k2k_2k2​ with the corrected value and repeat step 4 until two values agree
Pseudocode
input f, x0, y0, h, x_end
x ← x0;  y ← y0
while x < x_end − h/2:
    k1 ← f(x, y)
    yp ← y + h·k1          # predictor
    k2 ← f(x + h, yp)
    y ← y + h/2·(k1 + k2)  # corrector
    x ← x + h
return y

Twice the work of Euler per step, but far fewer steps for the same accuracy.

When to use it

Euler and modified Euler: method profile

Best case
  • Teaching, quick sketches, very simple models
  • Heun: modest accuracy (3–4 digits) with little code
  • Euler inside game physics and real-time loops, where speed matters more than accuracy
Worst case
  • Long time spans: errors accumulate (first order)
  • Stiff equations: unstable unless hhh is tiny
  • Oscillations and orbits: Euler adds energy and spirals outwards (Lecture 22)
Best suited for
  • Prototyping a model
  • Heun as a building block: predictor–corrector schemes
  • Taylor and Picard: deriving series solutions by hand; existence proofs
Avoid when
  • Production simulations (use RK4 or adaptive solvers)
  • Stiff problems (use implicit methods)
  • When 6+ digits are needed

Rule of thumb: Euler to understand, Heun for a quick improvement, RK4 (Lecture 22) for real work.
