Lagrange and Divided-Difference Interpolation

Interpolation when the data are not equally spaced: Lagrange's formula built from basis polynomials, Newton's divided differences that grow one point at a time, inverse interpolation, and why both beat solving for the coefficients.

Why this lecture

The problem: a sensor that skipped some readings

A data logger was supposed to record every second, but readings at t=3t = 3t=3 and 444 were lost. We need the value at t=3t = 3t=3.

  • The remaining times 0, 1, 2, 5 are not equally spaced
  • Newton's forward and backward formulas (Lecture 16) do not apply
  • We still want the polynomial through all the points, and a quick way to update it when a reading is recovered
  • Two answers: Lagrange (one formula, any spacing) and divided differences (a table that grows)

The idea in one picture

Three dots, not necessarily equally spaced.Build a small curve that passes through dot 0 and is zero at the other x values.Another one for dot 1: correct there, zero at x₀ and x₂.And one for dot 2.Add the three curves. At each x only one of them is non-zero, so the sum passes through every dot.
In plain words
  • Points need not be equally spaced
  • Give each point its own small curve: right at that point, zero at the others
  • Add them up: the sum passes through every point

The method, step by step

Lagrange interpolation, step by step

  1. List the points (x0,y0),…,(xn,yn)(x_0, y_0), \dots, (x_n, y_n)(x0​,y0​),…,(xn​,yn​); all xix_ixi​ must be different
  2. For each iii: numerator ∏j≠i(x−xj)\prod_{j\ne i}(x - x_j)∏j=i​(x−xj​), denominator ∏j≠i(xi−xj)\prod_{j\ne i}(x_i - x_j)∏j=i​(xi​−xj​)
  3. Compute Li(x)L_i(x)Li​(x) = numerator / denominator
  4. Add up yiLi(x)y_iL_i(x)yi​Li​(x)
  5. Check: the Li(x)L_i(x)Li​(x) must add up to 1
Pseudocode
input x[0..n], y[0..n], X
sum ← 0
for i = 0 … n:
    L ← 1
    for j = 0 … n, j ≠ i:
        L ← L·(X − x[j]) / (x[i] − x[j])
    sum ← sum + y[i]·L
return sum

Two nested loops: O(n2)O(n^2)O(n2) work for every new XXX.

Newton's divided differences

Divided differences: differences divided by the x-gap they spanf[xi,xi+1]=f[xi+1]−f[xi]xi+1−xif[xi,…,xi+k]=f[xi+1,…,xi+k]−f[xi,…,xi+k−1]xi+k−xi\begin{aligned} f[x_i, x_{i+1}] &= \frac{f[x_{i+1}] - f[x_i]}{x_{i+1} - x_i} \\ f[x_i, \dots, x_{i+k}] &= \frac{f[x_{i+1}, \dots, x_{i+k}] - f[x_i, \dots, x_{i+k-1}]}{x_{i+k} - x_i} \end{aligned}f[xi​,xi+1​]f[xi​,…,xi+k​]​=xi+1​−xi​f[xi+1​]−f[xi​]​=xi+k​−xi​f[xi+1​,…,xi+k​]−f[xi​,…,xi+k−1​]​​
Newton's divided-difference formulaP(x)=f[x0]+f[x0,x1](x−x0)+f[x0,x1,x2](x−x0)(x−x1)+⋯\begin{aligned} P(x) = {} & f[x_0] + f[x_0,x_1](x - x_0) \\ & + f[x_0,x_1,x_2](x - x_0)(x - x_1) + \cdots \end{aligned}P(x)=​f[x0​]+f[x0​,x1​](x−x0​)+f[x0​,x1​,x2​](x−x0​)(x−x1​)+⋯​
  • Equal spacing: f[x0,…,xk]=Δky0/(k! hk)f[x_0, \dots, x_k] = \Delta^k y_0/(k!\,h^k)f[x0​,…,xk​]=Δky0​/(k!hk), giving the forward formula back
  • Order of the points does not matter: divided differences are symmetric
  • Adding a point adds one term; nothing else changes
  • Evaluate with nested multiplication (Horner): O(n)O(n)O(n) per xxx

The method, step by step

Divided differences, step by step

  1. Column 0: the yiy_iyi​
  2. Column kkk: (lower entry)−(upper entry)xi+k−xi\dfrac{\text{(lower entry)} - \text{(upper entry)}}{x_{i+k} - x_i}xi+k​−xi​(lower entry)−(upper entry)​, where the denominator spans all points involved
  3. Read the coefficients f[x0],f[x0,x1],…f[x_0], f[x_0,x_1], \dotsf[x0​],f[x0​,x1​],… from the top edge
  4. Evaluate P(x)P(x)P(x) by nested multiplication
  5. New point? Add it at the bottom: one new entry per column, one new term
Pseudocode
input x[0..n], y[0..n], X
c ← copy of y
for k = 1 … n:               # build table
    for i = n … k:
        c[i] ← (c[i] − c[i−1]) / (x[i] − x[i−k])
# c[k] = f[x0, …, xk]
p ← c[n]
for k = n−1 … 0:             # Horner
    p ← c[k] + (X − x[k])·p
return p

O(n2)O(n^2)O(n2) once for the table, then O(n)O(n)O(n) for each XXX.

When polynomial interpolation goes wrong

Limitations shown failing

  • Many points, high degree: wild swings near the ends (Runge); look at the LiL_iLi​ values: some are huge
  • Noisy data: the polynomial passes exactly through every error
  • Inverse interpolation far from the points is unreliable
  • Lagrange costs O(n2)O(n^2)O(n2) per evaluation and restarts when a point is added

When to use it

Lagrange and divided differences: method profile

Best case
  • A handful of points with any spacing
  • Divided differences: points arriving one at a time
  • Exact for polynomial data; elegant formulas for theory
Worst case
  • Many equally spaced points (Runge oscillation)
  • Noisy data: the curve chases the noise
  • Lagrange evaluated naively at many xxx: O(n2)O(n^2)O(n2) each
Best suited for
  • Irregular samples, few points
  • Deriving quadrature rules (Simpson, Gauss: Lecture 20)
  • Exact algebra over finite fields: secret sharing, error-correcting codes
Avoid when
  • Long data sets (splines, Lecture 18)
  • Noisy measurements (least squares, Lecture 23)
  • Solving for the monomial coefficients (Vandermonde)

Rule of thumb: few points, any spacing → divided differences (or barycentric Lagrange); many points → splines; noisy points → least squares.
