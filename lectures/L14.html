Why this lecture

The problem: a plate with a million grid points

The plate from Lecture 12, now on a fine grid so that the temperature map is smooth.

  • A 100 × 100 grid: 10 000 unknowns; the full matrix has 10810^8108 entries (800 MB) but only 5 per row are nonzero: 99.95% zeros
  • A 1000 × 1000 grid: 10610^6106 unknowns; dense elimination needs 8 TB and about 21 years
  • Yet each equation is tiny: "each temperature is the average of its four neighbours"
  • Idea: guess all temperatures, then keep replacing each one by the average of its neighbours

The idea in one picture

A point on a heated plate, surrounded by four neighbours.We do not know its temperature yet: start with any guess.Rule: a point is the average of its neighbours.So replace the guess by that average.One "sweep" applies the rule at every point of the grid.Sweep again and again. In plain words

  • Sweep through all unknowns again and again

The method, step by step

Jacobi's method, step by step

  1. Check (or arrange) that the system is diagonally dominant
  2. Rewrite equation iii as xi=(bi−∑j≠iaijxj)/aiix_i = (b_i - \sum_{j\ne i} a_{ij}x_j)/a_{ii}xi​=(bi​−∑j=i​aij​xj​)/aii​
  3. Choose a start, usually x(0)=0\mathbf{x}^{(0)} = \mathbf{0}x(0)=0
  4. Compute all new xix_ixi​ from the old vector
  5. Stop when ∥x(k+1)−x(k)∥∞<ε\|\mathbf{x}^{(k+1)} - \mathbf{x}^{(k)}\|_\infty < \varepsilon∥x(k+1)−x(k)∥∞​<ε; otherwise repeat step 4
Pseudocode
input A, b, x (start), tol, N
repeat up to N times:
    for i = 1 … n:
        s ← b[i] − Σ_{j≠i} a[i][j]·x[j]
        x_new[i] ← s / a[i][i]
    if max |x_new − x| < tol:
        return x_new
    x ← x_new
stop: no convergence

Two vectors: old and new. Every xix_ixi​ can be updated at the same time, so Jacobi runs well in parallel (GPUs).

The method, step by step

Gauss–Seidel, step by step

Use each new value as soon as it is computed:   xi(k+1)=1aii(bi−∑j<iaijxj(k+1)−∑j>iaijxj(k))\;x_i^{(k+1)} = \dfrac{1}{a_{ii}}\Big(b_i - \sum_{j<i} a_{ij}x_j^{(k+1)} - \sum_{j>i} a_{ij}x_j^{(k)}\Big)xi(k+1)​=aii​1​(bi​−∑j<i​aij​xj(k+1)​−∑j>i​aij​xj(k)​)

  1. Arrange the system so that it is diagonally dominant
  2. Start with x(0)\mathbf{x}^{(0)}x(0) (often 0\mathbf{0}0)
  3. Update x1x_1x1​; then x2x_2x2​ using the new x1x_1x1​; then x3x_3x3​ using the new x1,x2x_1, x_2x1​,x2​; …
  4. Stop when the largest change in a sweep is below ε\varepsilonε
  5. Matrix form: (D+L)x(k+1)=b−Ux(k)(D + L)\mathbf{x}^{(k+1)} = \mathbf{b} - U\mathbf{x}^{(k)}(D+L)x(k+1)=b−Ux(k)
Pseudocode
input A, b, x (start), tol, N
repeat up to N times:
    change ← 0
    for i = 1 … n:
        s ← b[i] − Σ_{j≠i} a[i][j]·x[j]
        new ← s / a[i][i]
        change ← max(change, |new − x[i]|)
        x[i] ← new        # overwrite now
    if change < tol: return x
stop: no convergence

One vector, overwritten in place: less memory and usually about twice as fast as Jacobi.

When does it converge?

Strict diagonal dominance in every row ⇒ Jacobi and Gauss–Seidel converge from any start∣aii∣>∑j≠i∣aij∣,i=1,…,n|a_{ii}| > \sum_{j \ne i} |a_{ij}|, \qquad i = 1, \dots, n∣aii​∣>j=i∑​∣aij​∣,i=1,…,n
The real reason: the error is multiplied by T at every stepe(k+1)=T e(k)  ⇒  e(k)=Tke(0)→0  ⟺  ρ(T)<1\mathbf{e}^{(k+1)} = T\,\mathbf{e}^{(k)} \;\Rightarrow\; \mathbf{e}^{(k)} = T^k\mathbf{e}^{(0)} \to \mathbf{0} \iff \rho(T) < 1e(k+1)=Te(k)⇒e(k)=Tke(0)→0⟺ρ(T)<1
  • ρ(T)=max⁡∣λi(T)∣\rho(T) = \max|\lambda_i(T)|ρ(T)=max∣λi​(T)∣, the spectral radius: the matrix version of ∣g′(r)∣|g'(r)|∣g′(r)∣ in Lecture 8
  • Each iteration multiplies the error by about ρ\rhoρ: about d/(−log⁡10ρ)d/(-\log_{10}\rho)d/(−log10​ρ) iterations for ddd digits
  • Diagonal dominance is sufficient, not necessary
  • For many matrices (including the plate): ρ(TGS)=ρ(TJ)2\rho(T_{GS}) = \rho(T_J)^2ρ(TGS​)=ρ(TJ​)2, so Gauss–Seidel needs half as many iterations

Recap: eigenvalues and the spectral radius

Eigenvalue λ and eigenvector vTv=λv,  v≠0⟺det⁡(T−λI)=0T\mathbf{v} = \lambda\mathbf{v}, \;\mathbf{v} \ne \mathbf{0} \quad\Longleftrightarrow\quad \det(T - \lambda I) = 0Tv=λv,v=0⟺det(T−λI)=0
2×2: the characteristic equationλ2−(tr⁡T) λ+det⁡T=0,ρ(T)=max⁡(∣λ1∣,∣λ2∣)\lambda^2 - (\operatorname{tr} T)\,\lambda + \det T = 0, \qquad \rho(T) = \max(|\lambda_1|, |\lambda_2|)λ2−(trT)λ+detT=0,ρ(T)=max(∣λ1​∣,∣λ2​∣)
  • Along an eigenvector, Tkv=λkvT^k\mathbf{v} = \lambda^k\mathbf{v}Tkv=λkv: it shrinks if ∣λ∣<1|\lambda| < 1∣λ∣<1, grows if ∣λ∣>1|\lambda| > 1∣λ∣>1
  • Any error is a mix of eigenvectors, so the largest ∣λ∣|\lambda|∣λ∣ wins in the end
  • ρ<1\rho < 1ρ<1: the iteration is a contraction, like ∣g′∣<1|g'| < 1∣g′∣<1
  • Eigenvalues return in ODE stability (Lecture 22) and in optimisation (Lecture 25)

When iteration does not work

Limitations shown failing

  • Not diagonally dominant: the same system with rows swapped has ρ=3.16\rho = 3.16ρ=3.16; the iterates explode
  • Fix: reorder the equations so the largest coefficient of each row is on the diagonal
  • Slow when ρ\rhoρ is close to 1: nearly parallel lines, fine grids (Jacobi needs millions of sweeps)
  • Accuracy only to the tolerance, and a small change is not always a small error when ρ≈1\rho \approx 1ρ≈1

When to use it

Jacobi, Gauss–Seidel and SOR: method profile

Best case
  • Huge sparse systems from grids: memory and work proportional to the number of nonzeros
  • Diagonally dominant or SPD matrices: guaranteed convergence
  • A good starting guess (the previous time step): few sweeps needed
Worst case
  • Not diagonally dominant and ρ(T)≥1\rho(T) \ge 1ρ(T)≥1: divergence
  • ρ\rhoρ close to 1 (fine grids): Jacobi and Gauss–Seidel crawl
  • Small dense systems: elimination is faster and exact
Best suited for
  • Heat, flow and electrostatics on grids (Laplace and Poisson equations)
  • Jacobi: parallel hardware (GPUs); Gauss–Seidel: sequential code, less memory
  • Smoothers inside multigrid; PageRank-type ranking iterations
Avoid when
  • Dense matrices with nnn in the thousands (use LU)
  • Problems needing many digits from a slowly converging iteration
  • Indefinite or non-dominant matrices (use Krylov methods such as GMRES)

Rule of thumb: sparse and huge → iterate (SOR or better); dense or small → factor. Always check dominance or ρ<1\rho < 1ρ<1 first.

Summary

Key points
  • Jacobi: solve row iii for xix_ixi​ using old values; Gauss–Seidel: use new values at once
  • Both are fixed-point iterations x=Tx+c\mathbf{x} = T\mathbf{x} + \mathbf{c}x=Tx+c; they converge iff ρ(T)<1\rho(T) < 1ρ(T)<1 (diagonal dominance is enough)
  • Gauss–Seidel is usually about twice as fast; SOR with a good ω\omegaω much faster
  • Use iteration for huge sparse systems; factorisation for small or dense ones
