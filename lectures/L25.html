The idea in one picture

A function of two variables drawn as a map: each ring is one height.Start anywhere. We want the bottom of the valley.Feel which way is steepest downhill and take a step that way.Look again from the new place, step again.The steps get shorter as the ground flattens.Keep going …… until the bottom: the minimum.If the steps are too long, each one jumps across the valley and lands higher. The learning rate matters.
In plain words
  • Training a model = finding the lowest point of an error surface
  • We cannot see the whole surface, only the slope where we stand
  • So step downhill, look again, and repeat

Golden-section search: shrink a bracket without derivatives

f unimodal on [a, b]; two interior points, g = (√5 − 1)/2 ≈ 0.618c=b−g(b−a),d=a+g(b−a)c = b - g(b - a), \qquad d = a + g(b - a)c=b−g(b−a),d=a+g(b−a)
Keep the part that must contain the minimumf(c)<f(d)  ⇒  [a,d],f(c)≥f(d)  ⇒  [c,b]f(c) < f(d) \;\Rightarrow\; [a, d], \qquad f(c) \ge f(d) \;\Rightarrow\; [c, b]f(c)<f(d)⇒[a,d],f(c)≥f(d)⇒[c,b]
  • Like bisection (Lecture 6), but compares two values instead of checking a sign
  • The kept interior point is reused: one new fff value per step, because g2=1−gg^2 = 1 - gg2=1−g
  • Bracket width × 0.618 each step: from 3 to 10−410^{-4}10−4 in 22 steps
  • Needs only a unimodal fff (one dip): no derivatives, very robust

The method, step by step

Golden-section search, step by step

  1. Choose a bracket [a,b][a, b][a,b] in which fff has a single minimum
  2. Place c=b−0.618(b−a)c = b - 0.618(b - a)c=b−0.618(b−a) and d=a+0.618(b−a)d = a + 0.618(b - a)d=a+0.618(b−a); evaluate f(c)f(c)f(c), f(d)f(d)f(d)
  3. If f(c)<f(d)f(c) < f(d)f(c)<f(d): b←db \leftarrow db←d, d←cd \leftarrow cd←c, new ccc; otherwise a←ca \leftarrow ca←c, c←dc \leftarrow dc←d, new ddd
  4. Evaluate fff only at the new point
  5. Stop when b−a<b - a <b−a< tolerance; answer (a+b)/2(a + b)/2(a+b)/2
Pseudocode
input f, a, b, tol
g ← (√5 − 1)/2
c ← b − g(b − a);  d ← a + g(b − a)
while b − a > tol:
    if f(c) < f(d):
        b ← d;  d ← c
        c ← b − g(b − a)
    else:
        a ← c;  c ← d
        d ← a + g(b − a)
return (a + b)/2

Store f(c)f(c)f(c) and f(d)f(d)f(d) so that each step costs one evaluation.

The method, step by step

Gradient descent, step by step

  1. Start at x0\mathbf{x}_0x0​; choose η\etaη (try 0.1, then adjust by factors of 3)
  2. Compute the gradient g=∇f(xk)\mathbf{g} = \nabla f(\mathbf{x}_k)g=∇f(xk​)
  3. Step: xk+1=xk−ηg\mathbf{x}_{k+1} = \mathbf{x}_k - \eta\mathbf{g}xk+1​=xk​−ηg
  4. Stop when ∥g∥\|\mathbf{g}\|∥g∥ or the change in fff is below a tolerance
  5. If fff increases, η\etaη is too large: halve it. Momentum: v←βv−ηg\mathbf{v} \leftarrow \beta\mathbf{v} - \eta\mathbf{g}v←βv−ηg,   x←x+v\;\mathbf{x} \leftarrow \mathbf{x} + \mathbf{v}x←x+v
Pseudocode
input ∇f, x0, η, tol, kmax
x ← x0;  v ← 0
for k = 1 … kmax:
    g ← ∇f(x)
    if ‖g‖ < tol: stop
    v ← β·v − η·g    # β = 0: plain GD
    x ← x + v
return x

When to use it

Optimisation methods: profile

Best case
  • Golden section: one variable, no derivatives, guaranteed for unimodal fff
  • Gradient descent: huge numbers of parameters, cheap steps, works with noisy (stochastic) gradients
  • Newton / Gauss–Newton: few parameters, high accuracy in few steps
Worst case
  • Golden section: several variables, functions with many dips
  • Gradient descent: ill-conditioned valleys; sensitive to η
  • Newton: Hessian too large to form; non-convex regions
Best suited for
  • Tuning one hyperparameter (golden section on validation error)
  • Training ML models: linear, logistic, neural networks (SGD, Adam)
  • Curve fitting and calibration (Gauss–Newton, Levenberg–Marquardt)
Avoid when
  • Problems with a closed-form solution (linear least squares)
  • Non-smooth or discrete objectives (use specialised methods)
  • Constrained problems without modification (Lagrange multipliers, linear programming)

Rule of thumb: few variables and smooth: Newton or quasi-Newton; many variables or huge data: (stochastic) gradient descent with a tuned learning rate.
