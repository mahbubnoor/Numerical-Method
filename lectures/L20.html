The idea in one picture

An integral is the area under a curve.Cut the area into strips. One strip with a straight top is a trapezoid: easy area.Add the strips: that is the trapezoidal rule.Small gaps remain where the curve bends. More strips make them smaller.Simpson's rule uses curved tops (parabolas over two strips): far more accurate for the same work.
In plain words
  • An integral is an area
  • Cut it into thin strips whose areas are easy, and add them
  • Better-shaped strips (curved tops) need far fewer of them

The method, step by step

Trapezoidal and Simpson's rules, step by step

  1. Choose nnn (even for Simpson 1/3) and h=(b−a)/nh = (b - a)/nh=(b−a)/n
  2. Tabulate xi=a+ihx_i = a + ihxi​=a+ih and yi=f(xi)y_i = f(x_i)yi​=f(xi​) for i=0,…,ni = 0, \dots, ni=0,…,n
  3. Trapezoidal: sum = ends + 2 × inside; multiply by h/2h/2h/2
  4. Simpson: sum = ends + 4 × odd + 2 × even (inside); multiply by h/3h/3h/3
  5. Check: repeat with nnn doubled; the change estimates the error
Pseudocode
input f, a, b, n   # n even
h ← (b − a) / n
T ← (f(a) + f(b)) / 2
S ← f(a) + f(b)
for i = 1 … n−1:
    y ← f(a + i·h)
    T ← T + y
    S ← S + (4 if i odd else 2)·y
return h·T,  h·S / 3

One loop, n+1n + 1n+1 function values, both rules at once.

When to use it

Numerical integration: method profile

Best case
  • Smooth integrands: Simpson gains a factor 16 per halving of hhh
  • Tabulated data at equal steps: trapezoidal or Simpson directly
  • Romberg or Gauss: many digits from few function values
Worst case
  • Singularities or infinite derivatives at an end point
  • Fast oscillations with too few samples (aliasing)
  • Jumps inside a panel
Best suited for
  • Areas, distances, energies and probabilities from measurements
  • Statistics and ML: AUC, expectations, normalising constants
  • Inside ODE methods (Heun = trapezoid, Milne = Simpson: Lectures 21–22)
Avoid when
  • Simpson with odd nnn (use 3/8 for one block)
  • Very high-order Newton–Cotes rules (negative weights, Runge-like trouble)
  • Integrals over many dimensions (use Monte Carlo)

Rule of thumb: tables → Simpson (trapezoidal for unequal or rough data); formulas → Gauss or an adaptive library routine; always compare two step sizes.
