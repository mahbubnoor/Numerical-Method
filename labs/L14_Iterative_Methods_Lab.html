Q1 Distinguish the Jacobi and Gauss–Seidel methods.
Both solve equation iii for xix_ixi​. Jacobi uses only values from the previous iteration (two vectors, easy to parallelise); Gauss–Seidel uses each new value as soon as it is computed (one vector, usually about twice as fast).
Q2 State a sufficient condition for convergence of the Jacobi and Gauss–Seidel methods.
Strict diagonal dominance: ∣aii∣>∑j≠i∣aij∣|a_{ii}| > \sum_{j\ne i}|a_{ij}|∣aii​∣>∑j=i​∣aij​∣ for every row. More generally, the iteration converges for every start iff the spectral radius of the iteration matrix is less than 1.
