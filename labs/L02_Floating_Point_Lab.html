Q6 Why is if (x == 0.3) dangerous after computing x = 0.1 + 0.2? What should be written?
Both sides carry different rounding errors (0.30000000000000004 vs 0.29999999999999998890), so the test is false. Write fabs(x - 0.3) < 1e-12, or a relative test fabs(x - y) <= 1e-12 * fabs(y).
