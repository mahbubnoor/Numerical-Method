Q4 What is Romberg integration?
Repeated Richardson extrapolation of trapezoidal values T(h),T(h/2),T(h/4),…T(h), T(h/2), T(h/4), \dotsT(h),T(h/2),T(h/4),…: Rk,j=Rk,j−1+(Rk,j−1−Rk−1,j−1)/(4j−1)R_{k,j} = R_{k,j-1} + (R_{k,j-1} - R_{k-1,j-1})/(4^j - 1)Rk,j​=Rk,j−1​+(Rk,j−1​−Rk−1,j−1​)/(4j−1), removing the h2,h4,…h^2, h^4, \dotsh2,h4,… error terms in turn.
Q5 State one advantage and one disadvantage of Gauss quadrature.
Advantage: nnn points integrate polynomials of degree 2n−12n - 12n−1 exactly, so very few function values are needed. Disadvantage: the points are irrational, so it cannot be used on equally spaced tabulated data.
