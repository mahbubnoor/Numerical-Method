Q2 Why are Runge–Kutta methods preferred to the Taylor series method?
They reach the same order using only values of fff, so no derivatives of fff have to be derived and coded for each new equation.

Q4 Why are predictor–corrector methods not self-starting?
Their formulas use values at several previous points (yn−3,…,yny_{n-3}, \dots, y_nyn−3​,…,yn​); at the start only y0y_0y0​ is known, so the first few values must come from a one-step method such as RK4.
Q5 What is a stiff differential equation?
One with components that decay at very different rates, so that explicit methods must use a step size set by the fastest (already negligible) component to stay stable, e.g. y′=−50(y−cos⁡x)y' = -50(y - \cos x)y′=−50(y−cosx). Implicit methods remove this restriction.
