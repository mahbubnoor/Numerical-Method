Q4 Why does the bracket in false position usually not shrink to zero?
If fff is convex (or concave) on the bracket, every chord lies on the same side of the curve, so every new point falls on the same side of the root. One endpoint is replaced every time; the other never moves.
Q5 Compare false position and bisection (three points).
Both bracket the root and always converge. Bisection uses only signs, has the guaranteed bound (b−a)/2n(b-a)/2^n(b−a)/2n, and is slow but steady. False position uses function values, is usually faster, but has no simple bound and can stall when one endpoint gets stuck.
