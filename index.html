How to use

Slides: →/Space next step, ← back, F full screen, S slide list. Worked solutions appear one line at a time: predict the next line before it appears.

Live code: every lecture has Python and C programs you can edit and run in the page (Ctrl+Enter). Change a number, press Run, see what happens. ⤓ downloads the file for Jupyter or gcc.

Labs: each lecture's lab has an explorer, a solver that builds the full iteration table for your own problem, coding tasks, and practice questions with answers.

Offline: everything is inside this folder: fonts, formulas, Python and C runners. Open index.html in any browser, no internet needed.
